# Приведение временных рядов к стационарности

Домашнее задание: анализ 6 временных рядов и приведение каждого к стационарному виду.

## Содержание

- `time_series_stationarity.ipynb` — ноутбук с полным разбором (выполнен, все выводы сохранены)
- `Series/` — исходные данные (6 CSV)
- `requirements.txt` — зависимости

## Ряды и итоговые преобразования

| Ряд | Частота | n | Преобразование |
|---|---|---|---|
| Продажи компании X | месяц | 77 | log → Δ₁ → минус сезонные дамми |
| Ограбления в Бостоне | месяц | 118 | log → Δ₁ |
| Пассажиры авиалиний | месяц | 144 | log → Δ₁ → Δ₁₂ |
| Температура (Nottingham Castle) | месяц | 240 | минус месячные средние |
| Dow Jones, закрытия | неделя | 162 | log → Δ₁ |
| Рождения девочек (Калифорния) | день | 365 | минус линейный тренд и дамми дней недели |

## Метод

Для каждого ряда: стабилизация дисперсии (Бокс–Кокс) → устранение сезонности → устранение тренда → проверка.

Критерий стационарности — согласие четырёх диагностик, а не одного теста:

1. ADF отвергает единичный корень (p < 0.05);
2. KPSS не отвергает стационарность (p > 0.05);
3. ACF затухает быстро, нет незатухающих пиков на сезонных лагах;
4. нет признаков передифференцирования (r ≤ −0.5 на соответствующем лаге + рост дисперсии).

## Основной результат

Стандартная схема «log + Δ₁ + Δ₁₂» подошла ровно одному ряду из шести (`airline`).
Для трёх рядов механическое её применение приводит к передифференцированию:
там, где тренд или сезонность детерминированные, дифференцирование заменяется
вычитанием МНК-компоненты (сезонные средние, линейный тренд, дамми дней недели).
